# UR5e + Qwen Agent 自主抓取控制系统

## 简介
本项目是一个整合了 UR5e 机械臂、Robotiq 2F-85 夹爪和 Qwen 大语言模型的自主抓取系统。它可以接收自然语言指令，通过 Function Calling 机制调用工具，自主规划动作序列，并在 MuJoCo 仿真环境或真实机器人上执行抓取和放置等操作。

系统配备**腕部 RGB-D 相机**，通过视觉感知（颜色分割 + 深度投影）实现物体自动检测和 3D 定位，无需预先知道物体坐标，模拟真实世界的感知-决策-执行闭环。

## 核心特性
- **腕部相机视觉感知**: 腕部安装 RGB-D 相机，通过 HSV 颜色分割 + 深度图反投影实现物体 3D 定位（平均精度 ~28mm），支持多位置扫描覆盖全桌面。
- **大模型决策 (Qwen Agent)**: 接入阿里云 DashScope 兼容的 OpenAI 接口，默认使用 Qwen-max，通过自然语言对话智能调度底层机器人的规划与动作。
- **双工作模式支持**: 支持 MuJoCo 仿真环境（默认）与真实 UR5e 机械臂环境的切换，一套代码能够无缝迁移。
- **丰富的机器人技能**: 内置 `scan_workspace`, `pick_and_place`, `pick_object`, `place_object`, `move_to`, `grasp`, `release`, `go_home` 等多种工具。
- **仿真交互**: 支持键盘切换相机视角（1=自由视角, 2=俯视, 3=侧视, 4=腕部相机第一人称），可实时查看腕部相机画面。
- **CLI 交互式控制台**: 提供便捷的人机交互终端，支持自然语言指令和 `home`, `scene`, `state`、`reset` 等快捷调试命令。

## 视觉感知流水线

腕部相机的物体检测和 3D 定位流程：

```
腕部相机 → RGB图像 + 深度图
               │
               ▼
         HSV 颜色分割 → 找到物体像素位置 (u, v)
               │
               ▼
         深度查询 → 获取距离 d (米)
               │
               ▼
         内参反投影 → 相机坐标系 3D 点
               │
               ▼
         外参变换 → 世界坐标系 (x, y, z)
```

- **多位置扫描**: 从 3 个位置（中心、左前、右前）分别拍摄，避免机械臂自遮挡
- **检测精度**: 平均误差 ~28mm，满足抓取任务需求

## 系统要求及安装

### 环境依赖
项目基于 `Python >= 3.10` 构建。主要依赖包涵盖：
- `mujoco >= 3.6.0`
- `openai >= 2.31.0`
- `opencv-python >= 4.13.0.92`
- `scipy >= 1.15.3`

### 安装步骤
推荐使用 [uv](https://github.com/astral-sh/uv) （或者 pip）进行依赖安装：
```bash
# 激活环境后使用 uv 同步依赖
uv sync
```
或者使用 pip：
```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
```

## 配置说明

在使用基于大语言模型的 Agent 智能体功能前，需先配置阿里云 DashScope API 密钥。可以通过环境变量配置：
```bash
export DASHSCOPE_API_KEY="your-api-key"
```
（或者直接在 `config.py` 中或实例化 `GraspingAgent` 时传入设定）。

## 运行与使用

你可以直接运行 `main.py` 进入控制系统：

### 1. 默认仿真模式
```bash
# 包含启动仿真环境、加载场景和开启 GUI 渲染，配置默认 qwen-max 模型
python main.py
```

### 2. 指定不同的大模型
```bash
# 可选模型包括 qwen-max, qwen-plus, qwen-turbo 等
python main.py --model qwen-plus
```

### 3. 连接真实机器人
```bash
# 以真实机械臂模式启动
python main.py --mode real --robot-ip 192.168.1.100
```

### 4. 无头模式 (关闭仿真 GUI 渲染)
```bash
python main.py --no-render
```

### 5. 单次指令执行 (非交互模式)
```bash
python main.py --task "抓取红色方块并将其放置到蓝色盒子里"
```

### 6. 测试腕部相机视觉系统
```bash
# 独立测试视觉检测精度，输出与真值的对比结果
python test_wrist_camera.py
```

## 在交互终端中的特殊命令
当在 CLI 控制台中出现 `🤖 请输入任务指令 >` 提示符时，你可以用自然语言与 Agent 对话，或者直接输入以下特殊指令：
- `home`：让机械臂复位到初始位姿
- `scene`：打印获取当前场景中的所有检测物体及其位姿信息
- `state`：打印当前机器人的工作状态及各个轴的关节信息
- `reset`：重置 Agent 对话历史，以清理多层对话带来的记忆包袱
- `quit` 或 `exit`：平稳关闭模拟器及退出整个程序

## 仿真窗口快捷键
在 MuJoCo 仿真窗口中，可以使用以下按键切换相机视角：

| 按键 | 视角 | 说明 |
|------|------|------|
| `1` | 自由视角 | 默认，可用鼠标拖拽旋转缩放 |
| `2` | 俯视相机 | 桌面正上方向下看全景 |
| `3` | 侧视相机 | 从侧面观察整体场景 |
| `4` | 腕部相机 | Eye-in-hand 第一人称视角，跟随机械臂移动 |

```

├── agent/                 # Qwen Agent 智能体层
│   ├── agent.py           # 多轮对话与工具调用循环
│   ├── prompts.py         # 系统提示词（含视觉感知工作流指引）
│   └── tools.py           # 工具定义与执行（含 scan_workspace）
├── robot/                 # 机器人接口统一封装层
│   ├── base.py            # 抽象基类（含 scan_workspace 接口）
│   ├── sim_robot.py       # MuJoCo 仿真实现（多位置扫描）
│   └── real_robot.py      # 真实 UR5e 实现（框架）
├── sim/                   # MuJoCo 仿真核心
│   ├── environment.py     # 环境管理（含键盘相机切换）
│   ├── camera.py          # 视觉感知模块：RGB-D 渲染、颜色分割、
│   │                      #   深度反投影、3D 坐标重建、检测可视化
│   └── controller.py      # 运动控制：IK 求解、轨迹插值、抓放序列
├── models/                # MuJoCo 场景模型
│   └── scene.xml          # UR5e + Robotiq + 桌面 + 物体 + 相机
├── test_wrist_camera.py   # 腕部相机视觉系统测试脚本
└── test_pick.py           # 抓取功能测试脚本
```

### 关键模块说明

- **`sim/camera.py`** — 视觉感知核心，实现完整的 RGB-D 物体检测流水线：
  - 相机内参矩阵计算（从 fovy 推导焦距）
  - 相机外参获取（从 MuJoCo 实时读取世界位姿）
  - 深度图处理（MuJoCo 线性深度 → 米）
  - 像素到世界坐标的 3D 反投影
  - HSV 颜色分割 + 轮廓检测
  - 检测结果可视化与保存

- **`robot/sim_robot.py`** — 仿真机器人实现，包含多位置扫描策略：
  - 3 个扫描位置覆盖桌面不同区域
  - 自动合并去重检测结果（按置信度保留最优）

- **`agent/prompts.py`** — Agent 系统提示词，指导 LLM 优先使用 `scan_workspace` 进行视觉感知后再执行操作。
